# Переменные в PHP

## В PHP для хранения данных есть специальный инструмент — переменные. Их часто сравнивают с коробками. В коробки можно складывать физические предметы, а на переменные — "наклеивать" метки (имена), чтобы описывать их содержимое (значение).

## Правила создания переменных в PHP:

- Имя переменной должно начинаться со знака доллара $.
- Имя может содержать буквы, цифры и символ подчеркивания _.
- Запрещено использовать специальные символы (например, @).

1. Первым символом после $ может быть буква или подчеркивание _, но не цифра.

## Рекомендации по именованию переменных (best practices):

1. Быть описательными. Имя должно ясно указывать, что хранит переменная. Например, $totalPrice (общая цена) — хорошо, $tp — плохо.
2. Избегать однобуквенных имен (кроме счетчиков в циклах).
3. Быть последовательными в выбранном стиле написания.

Избегать общих имен. Например, $data — плохо, $userData или $productList — хорошо.

## Стили написания для имен из нескольких слов:

### camelCase (верблюжий регистр):

Первое слово с маленькой буквы, последующие — с большой. Например, $userAge.

Каждое слово с большой буквы. Например, $UserAge.

### snake_case (змеиный регистр):

Все слова в нижнем регистре, разделены подчеркиванием. Например, $user_age.

Большинство PHP-разработчиков предпочитают использовать camelCase для переменных. Главное — быть последовательным. В этом курсе мы будем использовать camelCase.
